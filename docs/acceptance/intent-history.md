# Intent 演进：保留结论与已停止路线

现行行为只以[规格顶部最新决定](../specs/2026-10-27-intent-gate-b-requirements.md)、[当前状态](2026-10-23-current-status-and-evidence-index.md)为准。以下是历史蒸馏，不是恢复旧机制的实施指令；旧逐票原文和联合工程记录见[历史原件](README.md#历史原件)。

2026-10-27 七票先后验证过声明展示前检查、有界修复、输入例外、澄清等待、纠正优先、从日志恢复状态及固定宿主/客户端消息边界。这些证据各有候选身份，只证明当时切片，不能合成当前产品通过。

2026-10-28 曾改为无工具的声明专用生成与同请求续步。该路线仍先结束失败 turn 再 followup，导致用户先看到 Failed；随后选择过 P3 客户端恢复呈现，但只实现规则核心，没有完整浏览器接线。

后续用户取消格式硬拦截、声明自动修复和自动续轮，恢复六桶 Intent 对话规范：每次真实用户输入后重新声明，同轮内部工具步骤不重复。P3 和格式恢复专用缓存/预算路线停止；保留独立工具权限、问题等待、同程序越过答案及 steering 执行检查。不能再把 P3 接线列为当前必做工作。

取消格式门与后续 persona 修订的既有验证记录分别保存在[当前验证摘要](../evidence/current-validation.json)，两轮不相加；真实模型语义与浏览器画面仍 GAP，未切换日常 profile。

[独立核验](2026-10-28-joint-goals-independent-verification.md)中的工具判读问题没有因取消格式门自动消失：成功/次序/逐目标/路径身份、metadata 旁路误判和日志 seq 完整性仍需逐项复核。真实模型是否主动采用 SDK/Hashline 仍未验证。下一步统一从[联合工作入口](../plans/2026-10-28-intent-gate-repair-implementation-plan.md)开始，不重复启动旧票据。
