## 已得到什么结论

[完整真实 S0](2026-10-26-evaluation-real-s0-modelscope-02.md)在同一 GLM-5.3-Flash/low 配置下执行全部 9 项：28 次请求、398,176 Token，请求对账和组装请求独立重放均 28/28。最终文件正确率为 stock-edit 3/3、Hashline 默认 2/3、Hashline + fallback 1/3；整轮 3 PASS / 3 GAP / 3 FAIL，冻结首次条件失败。

这些结果足以支持**当前样本不支持默认推广，应停止当前扩样路径**；不足以支持某种编辑机制在所有模型/任务上普遍优劣。三臂共享 persona/Intent/PTC、工具和 SDK 不同，属于工具配置比较，不是两个原生 preset 的纯策略消融。fallback 少耗 Token 同时少完成任务，不能作为节省成本证明。

[后续离线审计](README.md#历史原件 "归档原件：docs/acceptance/2026-10-26-evaluation-payload-prompt-audit.md")已修复坏 header→apply_patch 的请求形状误标，保留实际执行模式 unknown 和旧协议兼容；6 个 Hashline 首请求均有方括号指引，未找到明确格式冲突。三个恢复样本首次缺方括号，修正后成功；三个失败样本只输出意图并正常 stop，未调用工具。后者的模型内部原因尚未知，没有证据证明执行器截断、Intent gate 拒绝或 Provider 异常。

这不是“必须继续开发才能拿到有效结果”：评测确实发现了当前配置的失败、恢复与成本，并阻止了证据不足的推广。它仍是可复用工具，未来可换模型/配置、重新冻结、复核文件与轨迹；本次负面结果不会消除它的用途。
